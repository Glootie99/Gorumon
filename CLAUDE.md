# Gorumon

El trabajo actual es el proyecto de automatización para negocios locales de Madrid Norte, en `automatizacion/`.
Su contexto completo (decisiones, restricciones legales, archivos) está aquí:

@automatizacion/CLAUDE.md

Material de origen para cualquier trabajo de producto o diseño (incluida la entrevista de `/impeccable init`):
- `automatizacion/docs/plan-el-pilar.md`: plan de negocio, DAFO, clientes objetivo, módulos, precios orientativos, guion de visita.
- `automatizacion/docs/maquetas-demo.md`: maquetas de gestoría, clínica y academia.
- `automatizacion/referencia/sistema-facturas-por-dentro.html`: cómo funciona el sistema de facturas de la gestoría piloto (el producto que se vende a gestorías).
- `automatizacion/datos/candidatos_madrid_norte.csv`: 170 negocios candidatos.

`automatizacion/web/index.html` es un primer intento de landing para gestorías; trátalo como borrador, no como identidad visual establecida.
No hay cifras medidas, testimonios, precios validados ni nombre comercial decidido: no inventarlos.
